# Tutorial 2 — FP16 artifact

[Tutorials](README.md) · [Precision](../methods/precision.md) · [Artifacts](../artifacts.md)

```bash
SOURCE=models/biomedical-ner
OUTPUT=artifacts/a1-fp16
lab quantisation fp16 "$SOURCE" --output "$OUTPUT" --task token-classification
lab quantisation validate "$OUTPUT" --source "$SOURCE"
cat "$OUTPUT/compression_manifest.json"
```

The source is untouched. The output is a normal Hugging Face checkpoint plus provenance. A valid
smoke report does not prove equivalent F1 or faster execution; add A0/A1 to a controlled experiment.
On CPU, FP16 forward validation can fail because kernel support differs from storage support.

For BF16 use the same steps with `bf16` and a different output directory.
